# SporeAPI

SporeAPI is a Kotlin library that you can use in your projects. It started as a Minecraft API and now supports Paper and Velocity plugins as well as any other JVM project, such as Discord bots. It includes features such as menus, messages, a logger, boss bars, commands, cooldowns, and much more!
